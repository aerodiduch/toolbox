# toolbox

[![License: MIT](https://img.shields.io/github/license/aerodiduch/toolbox)](LICENSE)

[English](README.md)

Las herramientas chicas que uso todos los días en la Mac y en Claude Code. Cada una tiene su repo con los pasos para instalarla; esta es la lista, y crece a medida que sumo más.

| Herramienta | Qué hace |
|---|---|
| [LidMute](https://github.com/aerodiduch/lid-mute) | App para la barra de menú de macOS que mutea el sonido cuando cerrás la tapa y lo deja muteado cuando la abrís. |
| [Image Links](https://github.com/aerodiduch/claude-image-links) | Mod de Claude Code: las imágenes que te manda Claude aparecen como chips arriba del prompt. Pasás el mouse y la ves; con un clic se abre en Vista Previa. |

# toolbox

[![License: MIT](https://img.shields.io/github/license/aerodiduch/toolbox)](LICENSE)

[Español](README.es.md)

The small tools I use every day on my Mac and in Claude Code. Each one has its own repo with its install steps; this is the list, and it grows as I add more.

| Tool | What it does |
|---|---|
| [LidMute](https://github.com/aerodiduch/lid-mute) | macOS menu bar app that mutes the sound when you close the lid and leaves it muted when you open it. |
| [Image Links](https://github.com/aerodiduch/claude-image-links) | Claude Code mod: the images Claude sends you show as chips above the prompt. Hover one to see it, click to open it in Preview. |
